# Narrative working chapters

This tranche responds to the request to remove generated-sounding slogans and use
learn.w4gz.com as a compositional reference. It does not introduce a new domain
model or rewrite user-authored records.

## Reference and decision

The reference uses named, numbered chapters, a single principal idea per scene,
and a relationship between one chapter and the next. We retain that reading
order and orientation, not its illustrations, introductory scroll sequence,
full-screen pacing, or copy. A working product must expose the next action
without requiring a tour.

Current records carry the meaning; the application does not manufacture a thesis.
A question is appropriate when it actually labels an input. A generic question
above an unrelated form is not a narrative.

## Reading order

- **Me:** selected Goal as the title; current Reality and Gap beside the next
  task; inspectable five-step arc; existing Diagnosis, Design, observed Outcome,
  Reflection and Principle in a story-so-far. The archive remains secondary to work.
- **Learning:** Reflection with its Goal/Problem/observed case, then Pattern with
  its supporting cases, then Principle with lifecycle and origin, then revision.
  Direct Principle capture and the library remain one chapter link away; a user
  need not complete a reflection to write a principle themselves.
- **Knowledge:** question, streamed answer, inspectable sources. No motivational
  epilogue. Partial answers, errors, provenance and the link back to Me remain.
- **Organization:** actual organization name and purpose, current observed issue,
  competing explanations, responsibilities, attributable contextual evidence.
  Existing governed operations are unchanged.

## Constraints

Chapter navigation is ordinary anchors, not scroll hijacking or a progress score.
Reading sequence is not a fabricated timeline: only existing selected-goal records
and explicit origin/case links can be shown. No new summaries or causal claims are
generated for visual effect. An accepted diagnosis is still labelled as a hypothesis.
Action completion never supplies an observed outcome. User content is never passed
through a slogan filter, translated, or removed for resembling retired interface copy.

Evidence, counter-evidence, uncertainty and permissions survive the copy cleanup.
Keep the Vietnamese-safe font stack from the font fix. Let long text wrap and the
page scroll; do not constrain an editable scene to a slide height.

## Verification contract

The UI source gate rejects the retired stock headlines in application JSX and the
translation catalog. It deliberately excludes user data and test fixtures.
Browser regressions must check actual record titles, chapter order, case context,
origin navigation even under a library search, keyboard access, language switching,
independent action/outcome states, and no horizontal overflow. Screenshots must
cover populated Vietnamese scenes as well as empty and English states.

Reference capture and browser fixtures are verification material, not user research
or evidence of product value. Real usage and reader feedback remain necessary to
judge whether this reading order helps users make decisions.
